### 4.6.1 What this file demonstrates

This worked example shows the authoring forms in one compilable file. Inline
math uses ordinary TeX braces, as in $\frac{a}{b}$, and a prose comparison
needs spaces, as in $n<10$ or the text n < 10.

The same relationship can be displayed on its own:

$$
\mathbf{A}\mathbf{x} = \lambda\mathbf{x}
$$

An equation number belongs after the opening display fence. Write the number
the SOURCE prints; it becomes the equation's id and nothing re-derives it.

$$ {#eq-4.12}
\mathbf{A}^\top\mathbf{A} = \mathbf{V}\mathbf{D}^2\mathbf{V}^\top
$$

An equation the source leaves unnumbered gets a slug instead, and the counter
supplies a number in document order:

$$ {#eq-two-step}
a(a\mathbf{x}) = a^2\mathbf{x}
$$

Prose never spells a number out. Reference the label and the text is filled
in from the number table: @eq:4.12 is the eigendecomposition above, @eq:two-step
composes the map with itself, and @definition:4.6 says what the map is.

:::definition[4.6 (Scaling map)]
A scaling map sends every :c[vector]{#_demo-concept} $\mathbf{x}$ to
$a\mathbf{x}$ for a fixed scalar $a$.
:::

:::example[#scaling-twice]
Applying the map of @definition:4.6 twice scales by $a^2$, which is @eq:two-step.
:::

### Why the counter matters :id[why-counted]

A heading can be numbered the same two ways. `### 4.6.1 …` above keeps the
source's number; `:id[why-counted]` here asks the counter for one, so this
heading is @sec:why-counted and stays correct when something is inserted
before it.

::::proof

:::step
Apply the map twice to obtain $a(a\mathbf{x})$.

::why[The first application replaces $\mathbf{x}$ by $a\mathbf{x}$.]
:::

:::step
Associativity gives $a^2\mathbf{x}$, as in @eq:two-step.
:::

::::

::::quiz

:::question{true}
Scaling by $a=1$ leaves every vector unchanged.

The resulting map is the identity because $1\mathbf{x}=\mathbf{x}$.
:::

:::question{false}
Scaling by $a=0$ is invertible.

Every input maps to the zero vector, so distinct inputs cannot be recovered.
:::
